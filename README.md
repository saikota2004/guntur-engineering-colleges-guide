# Guntur Engineering Colleges Guide

A web-based guide to engineering colleges and universities in and around Guntur, Andhra Pradesh.

The website is designed to help students explore colleges, compare important admission details, and find information about courses, cutoffs, fees, facilities, and other college-related details in one place.

## 🌐 Website

**Live Website:**  
https://saikota2004.github.io/guntur-engineering-colleges-guide/

**GitHub Repository:**  
https://github.com/saikota2004/guntur-engineering-colleges-guide

---

## 📌 Features

- 🔎 Search engineering colleges
- 📍 Browse colleges based on location
- 🎓 View college and university details
- 📊 Search/filter using EAPCET cutoff ranks
- 📝 Admission information
- 💻 Courses offered
- 🏫 College type — Autonomous / Affiliated
- 🎯 Category-wise cutoff information
  - OC
  - BC
  - SC
  - ST
  - EWS
- 💰 Management quota fee information
- 🎓 Fee concession information
- 🏢 College facilities
- 📍 Location information
- 🗺️ Google Maps location references
- 📱 Student-friendly interface

---

## 🏫 Information Covered

| Category | Information |
|---|---|
| College | College name |
| Location | City / area |
| Admission | EAPCET / JEE Main |
| Cutoff | Department and category-wise ranks |
| Categories | OC / BC / SC / ST / EWS |
| Affiliation | JNTUK / JNTUA / Other |
| College Status | Autonomous / Affiliated |
| Courses | Engineering branches offered |
| Fees | Management quota / other available information |
| Concessions | Available fee concessions |
| Facilities | Campus and student facilities |
| Location | Maps/location information |

> **Note:** Cutoff ranks, fees, admission rules, and other college information can change from year to year. Students should verify important admission and fee details with the respective college or official admission authorities before making decisions.
